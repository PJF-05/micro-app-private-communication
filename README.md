# micro-app-private-communication

#### 介绍
问题：
调查并实践了一些微前端框架，发现基本都是共享式通信；例如如果子应用a想发送一些私密性消息给子应用b, 一旦其他子应用订阅了该事件就可以获取到该消息。
解决：
主应用创建全局发布订阅通信，主应用为子应用分别创建订阅发布服务，但其中主应用的发布替代子应用发布功能，而子应用真正的发布功能由主应用就控制。
